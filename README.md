# 默哀报

飞书 AI 绝活大会「线上黑客松」参赛作品。

每周把飞书多维表格里死掉的项目写成一份讣告小报，再发回飞书群和云文档。

**飞书读表 → Grok 验尸写报 → 飞书收报。** 三步都在核心运行里。

## 它解决什么

项目很少被正式宣布死亡。它们停在「进行中」，负责人已读不回，截止日期发臭。默哀报把验尸写成可以传阅的一版报纸，让「下周再说」有案可查。

## 核心运行

| 谁 | 干什么 |
|---|---|
| 飞书多维表格 | 项目名、负责人、状态、最后更新、截止日期 |
| Grok | 判定死亡，写头版、讣告、犯罪栏、墓志铭 |
| 飞书群机器人 / 云文档 | 收下本周讣告 |

沉默 ≥ 21 天、状态停摆、截止日期逾期、或负责人离职，按死亡处理。

## 上手

完整配置（自建应用权限、表格字段、机器人、样例 CSV）见仓库跑起来之后的 **`/guide`**，或直接看下面最短路径。

```bash
git clone https://github.com/19960705/moai-bao.git
cd moai-bao
npm install
npm run dev
```

1. 开放平台建企业自建应用，开通「读多维表格」「创建/编辑云文档」，发布给自己。
2. 建多维表格，列名：`项目名` `负责人` `状态` `最后更新` `截止日期`。可导入 [`public/guide/bitable-sample.csv`](public/guide/bitable-sample.csv)。把应用加成协作者。
3. 群里加自定义机器人，复制 Webhook。
4. 打开默哀报 → **入内** → **编辑部** 填 App ID / Secret / app_token / table_id / Webhook → 保存钥匙。
5. **停尸房** → 从飞书抬出 → **编辑部** → 让主笔写本周讣告 → 发往飞书。

不填飞书也能看复明日集团演示报，但那不算有效参赛。
