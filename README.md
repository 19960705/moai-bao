# 默哀报

飞书 AI 绝活大会参赛作品。每周把飞书多维表格里死掉的项目写成一份讣告小报。

沉默超过三周、状态停摆、截止日期发臭，或负责人已离职的，一律按死亡处理。

## 本地运行

```bash
npm install
npm run dev
```

打开终端提示的地址。演示数据（复明日集团）会直接印在头版，不必先接飞书。

## 飞书（投稿时再接）

1. 入内登录
2. 编辑部填自建应用 App ID / Secret
3. 填多维表格 token、表 ID、字段名
4. 停尸房「从飞书抬出」
5. 编辑部「让主笔写本周讣告」→「发往飞书」

不填飞书也能看报、开棺、录 Demo。
